# invai-web

The dashboard for owners, office staff, designers and DTF vendors (the vendor portal is a set of routes here, shown by organization type).

**Stack:** Vite 8, React 19, TanStack Router (file routes in `src/routes`), TanStack Query with the typed oRPC client (`src/lib/rpc.ts`), TanStack Table + Virtual, shadcn/ui from `@invai/ui`, Recharts, OpenSeadragon for gang-sheet previews, Konva for the design/template editor, AI SDK + assistant-ui for the assistant.

It is a single-page app: everything is behind a login, so there's no server rendering. `pnpm build` outputs static files to `dist/`, which `invai-infra` serves from S3 + CloudFront.

```
cp .env.example .env
pnpm install
pnpm dev          # http://localhost:5173 (needs invai-backend on :3000)
```

`src/routeTree.gen.ts` is generated by the router plugin on first `pnpm dev`.

```
pnpm typecheck && pnpm lint && pnpm test   # unit tests (Vitest)
pnpm e2e                                   # Playwright, against a running stack
```

**Version note for AI coding assistants:** TanStack Table is v9, Vite is v8, AI SDK is v7, Zod is v4. Check the package versions before writing code.
